💻 ITM DSA Repository

Data Structures and Algorithms using Java

A beginner-friendly collection of Data Structures and Algorithms implementations using Java, based on the ITM University syllabus.

This repository contains topic-wise Java programs, algorithm implementations, and practice problems covering all five units of the DSA curriculum.

---

📚 Course Contents

| Unit | Topics |
|---|---|
| [Unit 1](Unit-1/README.md) | Arrays, Strings, Sparse Matrices, Linked Lists |
| [Unit 2](Unit-2/README.md) | Stacks, Queues, Polish Notations, Recursion |
| [Unit 3](Unit-3/README.md) | Trees, Binary Trees, Binary Search Trees |
| [Unit 4](Unit-4/README.md) | Graphs, BFS, DFS, Shortest Paths, MST |
| [Unit 5](Unit-5/README.md) | Sorting, Searching, File Structures, Hashing |

🚀 How to Run Java Programs

Step 1: Clone the repository
git clone https://github.com/HexGit-stack/-ITM-DSA-Repository.git

Step 2: Navigate to the required Java program.

Step 3: Compile the program.
javac ProgramName.java

Step 4: Run the program.
java ProgramName
