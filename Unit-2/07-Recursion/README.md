# Recursion

## Definition
Recursion is a programming technique in which a method calls itself to solve a problem. A recursive method breaks a problem into smaller subproblems until it reaches a base condition.

## Key Components
1. **Base Case:** The condition that stops recursive calls.
2. **Recursive Case:** The part where the method calls itself with a smaller or simpler input.

## Examples of Recursion
- Factorial calculation
- Fibonacci series
- Sum of natural numbers
- Reversing a number

## Java Program
`Recursion.java`

## Sample Output

Factorial of 5: 120
Fibonacci Series: 0 1 1 2 3 5 8
Sum of first 5 natural numbers: 15


## Time Complexity

| Operation | Time Complexity |
|---|---|
| Factorial | O(n) |
| Fibonacci (simple recursive) | O(2^n) |
| Sum of natural numbers | O(n) |

## Space Complexity
O(n) for these recursive methods because of the function call stack.
