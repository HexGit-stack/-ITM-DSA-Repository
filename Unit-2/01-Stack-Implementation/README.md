# Stack Implementation

## Definition
A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle. The element inserted last is removed first.

## Types of Implementation
1. Array Implementation
2. Linked List Implementation

## Basic Operations
- Push: Adds an element to the stack.
- Pop: Removes the top element.
- Peek: Displays the top element.
- Display: Shows all stack elements.

## Java Program
StackImplementation.java

## Sample Output

Array Stack:
10 20 30
Popped: 30
Top element: 20

Linked List Stack:
30 20 10
Popped: 30

## Time Complexity

| Operation | Time Complexity |
|---|---|
| Push | O(1) |
| Pop | O(1) |
| Peek | O(1) |
| Display | O(n) |
