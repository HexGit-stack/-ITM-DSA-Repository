# Queue Implementation

## Definition
A Queue is a linear data structure that follows the FIFO (First In, First Out) principle. The element inserted first is removed first.

## Types of Implementation
1. **Array Implementation:** Stores queue elements in an array.
2. **Linked List Implementation:** Stores elements using connected nodes.

## Basic Operations
- Enqueue: Adds an element to the rear of the queue.
- Dequeue: Removes an element from the front.
- Peek: Displays the front element.
- Display: Shows all queue elements.

## Time Complexity

| Operation | Array | Linked List |
|---|---|---|
| Enqueue | O(1) | O(1) |
| Dequeue | O(1) | O(1) |
| Peek | O(1) | O(1) |
| Display | O(n) | O(n) |
