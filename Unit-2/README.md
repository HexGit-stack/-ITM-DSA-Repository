Unit 2 – Stacks, Queues and Recursion

This unit covers stack and queue data structures, expression evaluation and recursion using Java.

Topics Covered

1. Stacks
- Introduction to Stacks
- Implementation using Arrays
- Implementation using Linked Lists
- Stack Operations

2. Polish Notations
- Infix Notation
- Prefix Notation
- Postfix Notation
- Infix to Postfix Conversion
- Postfix Expression Evaluation

3. Queues
- Representation of Queues
- Implementation using Arrays
- Implementation using Linked Lists
- Circular Queue
- DeQueue
- Priority Queue

4. Recursion
- Introduction to Recursion
- Recursive Programs
- Tower of Hanoi Problem

Programming Language
Java

Difficulty Level
Beginner
