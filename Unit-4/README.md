Unit 4 – Graphs

This unit covers Graph Data Structures, graph representation, graph traversal techniques, shortest path algorithms and Minimum Spanning Trees using Java.

Topics Covered

1. Introduction to Graphs
- Definition of Graphs
- Graph Terminology
- Vertices and Edges
- Degree of a Vertex
- Paths and Cycles
- Connected and Disconnected Graphs

2. Representation of Graphs
- Adjacency Matrix
- Adjacency List
- Graph Representation using Java

3. Directed Graphs
- Introduction to Directed Graphs
- Directed and Undirected Graphs
- Indegree and Outdegree

4. Directed Acyclic Graph (DAG)
- Introduction to DAG
- Properties of DAG
- Topological Sorting

5. Shortest Path Algorithms
- Introduction to Shortest Path
- Dijkstra's Algorithm
- Bellman-Ford Algorithm

6. Graph Traversal
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Graph Traversal using Java

7. Minimum Cost Spanning Tree
- Introduction to Minimum Spanning Tree
- Kruskal's Algorithm
- Prim's Algorithm

Programming Language
Java

Difficulty Level
Beginner to Intermediate
