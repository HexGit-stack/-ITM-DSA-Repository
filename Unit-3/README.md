Unit 3 – Trees

This unit covers Tree Data Structures, Binary Trees, Tree Traversal techniques and Binary Search Trees using Java.

Topics Covered

1. Trees
- Introduction to Trees
- Definition of Trees
- Tree Terminology
- Root, Parent, Child and Leaf Nodes
- Height and Depth of Trees

2. Binary Trees
- Introduction to Binary Trees
- Representation of Binary Trees in Memory
- Array Representation
- Linked Representation
- Traversing Binary Trees
  - Inorder Traversal
  - Preorder Traversal
  - Postorder Traversal

3. Extended Binary Trees
- Introduction to Extended Binary Trees
- Representation of Extended Binary Trees
- Properties of Extended Binary Trees

4. Threaded Binary Trees
- Introduction to Threaded Binary Trees
- Types of Threaded Binary Trees
- Inorder Threaded Binary Trees
- Traversal of Threaded Binary Trees

5. Operations on Binary Trees
- Creation of Binary Trees
- Insertion of Nodes
- Deletion of Nodes
- Searching for Nodes
- Tree Traversal Operations

6. Search Trees
- Introduction to Binary Search Trees (BST)
- Searching in BST
- Insertion in BST
- Deletion in BST
- Finding Minimum and Maximum Elements

Programming Language
Java

Difficulty Level
Beginner
