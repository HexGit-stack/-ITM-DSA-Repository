# Trees

## Definition
A Tree is a non-linear hierarchical data structure consisting of nodes connected by edges. It starts with a root node and contains parent-child relationships.

## Basic Terminology
- **Root:** The topmost node of a tree.
- **Node:** An individual element in a tree.
- **Edge:** A connection between two nodes.
- **Parent:** A node that has child nodes.
- **Child:** A node connected below another node.
- **Leaf Node:** A node that has no children.
- **Sibling:** Nodes having the same parent.
- **Degree:** Number of children of a node.
- **Level:** Position of a node in the tree.
- **Height:** The longest path from a node to a leaf.

## Key Features
- Trees represent hierarchical relationships.
- They are non-linear data structures.
- Each child has exactly one parent, except the root.
- Trees contain no cycles.
