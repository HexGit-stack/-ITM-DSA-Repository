🤝 Contributing to ITM DSA Repository

Thank you for your interest in contributing to the ITM DSA Repository!

This project aims to help students learn Data Structures and Algorithms using beginner-friendly Java programs.

We welcome contributions from students and developers.

📌 Contribution Guidelines

You can contribute by:

- Adding new Java programs.
- Improving existing code.
- Fixing programming errors.
- Improving documentation.
- Adding new practice problems.
- Optimizing algorithms.

📂 Folder Organization

Every contribution should be placed in its appropriate unit and topic folder.

Example:

Unit-1/
└── Arrays/
    ├── ArrayTraversal.java
    ├── ArrayInsertion.java
    ├── ArrayDeletion.java
    └── README.md


💻 Coding Standards

Please follow these rules:

1. Write programs in Java.
2. Use meaningful class and variable names.
3. Keep code beginner-friendly.
4. Add comments wherever necessary.
5. Include sample output.
6. Mention time and space complexity where applicable.
7. Test your code before submitting.

🚀 How to Contribute

Step 1: Fork the Repository

Create your own copy of this repository using the Fork button.

Step 2: Clone Your Fork
git clone YOUR_FORK_URL

Step 3: Create a Branch
git checkout -b add-new-program

Step 4: Add Your Java Program

Place your program inside the correct unit and topic folder.

Step 5: Commit Your Changes
git add .
git commit -m "Add new Java program"


Step 6: Push Your Changes
git push origin add-new-program


Step 7: Create a Pull Request

Open your fork on GitHub and create a Pull Request to the original repository.

⚠️ Important Rules

- Avoid uploading duplicate programs.
- Do not upload copyrighted material without permission.
- Keep your code readable.
- Do not submit untested programs.
- Follow the existing folder structure.

🎯 Our Goal

To build a complete, beginner-friendly DSA learning resource using Java for students of ITM University and the wider programming community.
