03 – Operations on Linear Arrays

Definition:
Array operations are the basic actions performed on an array to manage and manipulate its elements.

Types of Array Operations

1. **Traversal:** Visiting and displaying every element.
2. **Insertion:** Adding a new element at a specified position.
3. **Deletion:** Removing an element from a specified position.
4. **Searching:** Finding the location of a particular element.
5. **Updating:** Modifying an existing element.

Java Program:
File:ArrayOperations.java

This program demonstrates traversal, insertion, deletion, searching and updating operations on a linear array.

Sample Output:
Original Array: 10 20 30 40 50
After Insertion: 10 20 25 30 40 50
After Deletion: 10 20 30 40 50
Element 40 found at index: 3
After Updating: 10 20 30 99 50


Time Complexity:

| Operation | Time Complexity |
|---|---|
| Traversal | O(n) |
| Insertion | O(n) |
| Deletion | O(n) |
| Searching | O(n) |
| Updating by index | O(1) |
