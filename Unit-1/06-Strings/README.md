# 06 – Strings

## Definition

A String is a sequence of characters used to store and manipulate text. In Java, strings are objects of the `String` class.
Strings are immutable in Java, which means their original value cannot be changed after creation.

## String Operations

1. **Declaration:** Creating a string variable.
2. **Length:** Finding the number of characters.
3. **Concatenation:** Joining two or more strings.
4. **Comparison:** Comparing two strings.
5. **Reversal:** Reversing the order of characters.
