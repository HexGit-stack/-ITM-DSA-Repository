02 – Linear Arrays

Definition:
A Linear Array is a collection of elements of the same data type stored in consecutive memory locations. Each element is accessed using an index.

Important Features:
- Stores multiple elements of the same data type.
- Uses zero-based indexing in Java.
- Has a fixed size after creation.
- Allows direct access to elements using their index.

Java Program
File:LinearArray.java

This program demonstrates:
- Array declaration
- Array initialization
- Accessing array elements
- Displaying elements using a loop

Sample Output:
Elements of Linear Array:

Index 0: 10
Index 1: 20
Index 2: 30
Index 3: 40
Index 4: 50

Time Complexity:

- Accessing an element: O(1)
- Traversing the array: O(n)
