# Circular Linked List

## Definition
A Circular Linked List is a linked list in which the last node points back to the first node instead of pointing to `null`. This creates a circular structure.

## Key Features
- The last node connects to the first node.
- Nodes can be traversed continuously.
- It can be implemented as a singly or doubly linked list.
- Useful in round-robin scheduling and circular queues.

## Operations Demonstrated
- Insertion at the end
- Deletion by value
- Traversal and display

## Java Program
CircularLinkedList.java

## Sample Output

Circular Linked List:
10 20 30 40
After deleting 20:
10 30 40


## Time Complexity

| Operation | Time Complexity |
|---|---|
| Insertion at end | O(1) |
| Deletion by value | O(n) |
| Traversal | O(n) |
