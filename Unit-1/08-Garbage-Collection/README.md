# 08 – Garbage Collection

## Definition

Garbage Collection is an automatic memory management process in Java that removes objects that are no longer reachable or used by a program.

It helps free heap memory and reduces the need for manual memory management.

## Important Points

- Java automatically manages memory.
- Garbage Collection removes unreachable objects.
- The JVM manages the garbage collection process.
- System.gc() can request garbage collection, but does not guarantee it will run immediately.
