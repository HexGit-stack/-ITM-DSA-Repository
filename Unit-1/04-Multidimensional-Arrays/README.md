# 04 – Multidimensional Arrays

## Definition
A Multidimensional Array is an array that contains other arrays. It is used to store data in rows and columns, similar to a matrix.
In Java, a two-dimensional array is commonly used to represent tables and matrices.

## Types
- Two-Dimensional Arrays (2D)
- Three-Dimensional Arrays (3D)

## Operations Covered
- Declaration and initialization
- Accessing array elements
- Traversing rows and columns
- Matrix addition

## Java Program
File:MatrixOperations.java

This program demonstrates two-dimensional array initialization, traversal and addition of two matrices.

## Sample Output
First Matrix:
1 2
3 4

Second Matrix:
5 6
7 8

Sum of Matrices:
6 8
10 12


## Time Complexity
- Traversal: O(rows × columns)
- Matrix Addition: O(rows × columns)
