# 09 – Header Linked List

## Definition

A Header Linked List is a linked list that contains a special node called the header node at the beginning of the list.

The header node may store information about the list or simply act as a starting point. It generally does not store regular data.

## Important Features

- Contains a special header node.
- The header node points to the first data node.
- Makes certain linked list operations easier.
- Can represent an empty list using a header node pointing to null.
